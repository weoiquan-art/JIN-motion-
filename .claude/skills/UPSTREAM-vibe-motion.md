# vibe-motion 技能的来源

- github.com/vibe-motion/skills(16 个技能,作者已停止维护)和 github.com/vibe-motion/sound(1 个),取自 2026-11-01 的最新提交。
- **两个上游仓库都没有授权文件**:本仓库是公开的,放进来是 JIN 明确要求的;作者或 JIN 觉得不合适就删掉整批(git rm -r .claude/skills/<名字>)。
- 省掉的:remotion-3d-ticker 的 26 MB 演示 GIF;sound 里作者自己的 Clash 代理脚本(clash_freesound.py,会改本机代理配置)和 references/local-setup.md。
- **sound 云端用不了**(Freesound 返回 403),只在 JIN 电脑上跑。其余技能很多会在运行时去 GitHub 克隆作者的另一个项目再渲染。
- 几个常用的:threejs-earth-render(地球)、remotion-3d-ticker(数字滚动)、fisheye-motion(推镜标注)、colorize(黑白变彩色)、disney-animation-rule-skill(动画原则)。
