# 动画经验：单个元素怎么动

## 1. 动画必须是"帧的纯函数"

- 每个值都由 `useCurrentFrame()` 算出来，不用 `useState`、`Math.random()`、`Date`。随机用确定性的 `hash(n)`、`noise1(x, seed)`。
- **帧号可能是小数**：运动模糊会在一帧里取多个子帧（如 127.75、128.25）。曲线、弹簧、切换判断都要对小数帧成立。弹簧用解析解（`springAt`），不用逐帧积分。
- 时间判断统一写成"相对节拍的 t"：`t = 帧 − 节拍帧`。

## 2. 踩拍曲线 whip（项目里所有重点动作都用它）

```ts
// t = 距离节拍的帧数。提前 0.75 帧开始，节拍那一帧就承载最大的一跳；
// 之后 easeOutBack 收尾。bounce 0 = 不过冲，0.5 ≈ 3%，1 ≈ 10%。
export const whip = (t: number, bounce = 1, dur = 8) => {
  const u = (t + 0.75) / dur;
  if (u <= 0) return 0;
  if (u >= 1) return 1;
  const c1 = 1.70158 * bounce;
  const c3 = c1 + 1;
  return 1 + c3 * (u - 1) ** 3 + c1 * (u - 1) ** 2;
};
// 出现（透明度/缩放）：节拍帧已经大半可见
export const pop = (t: number) => clamp(whip(t, 0, 4) * 1.15);
```

- 为什么提前 0.75 帧：运动模糊的快门是以帧为中心 ±0.25 帧，提前 0.75 帧刚好不影响前一帧，而节拍帧已经有明显变化。
- `dur` 越短，变化越集中在节拍帧：元素出现用 4，元素位移用 6，镜头用 8–14。
- 过冲：镜头 0.4–0.6，元素 1–1.5，"砸字" 1.3–1.6。
- 别用 ease-in 做踩拍动作，最大变化会晚 2 帧。

## 3. 打字

- 布局一开始就固定：整句都渲染，没打到的字透明。不会边打边挪位置，居中也不会抖。
- 每个字落在自己的网格时间上（8 分音符慢打、16 分音符快打）；太长时步长自动减半，保持在网格上。
- 空格不是一次按键：让它和下一个字同时出现，否则镜头会在没有声音的时候动一下。
- 光标：放在最后一个已出现字后面的**零宽** `inline-block` 里，绝对定位一根竖条，不影响排版。打字时常亮，打完按拍闪（每拍前半拍亮）。
- 镜头跟字：每个字把镜头推一格，推动**从这个字的时间开始**（用 whip），不要用从下一帧才开始动的 easeOut。
- 某几个字要特殊效果（发光、放大）时，给 `TypeLine` 传按字的样式函数；别叠一个"发光副本"，估算宽度会错位，出现重影。

## 4. 挤压和拉伸（"挤破脑袋"）

- 两面墙的间距决定字的横向缩放：`sx = clamp((间距 − 边距) / 字宽, 0.12, 1)`。
- 体积感：`sy = 1 + 0.6 × (1 − sx)`。系数太大，字会顶到上面的文字。
- 每个字按挤压量抖动、轻微旋转（`noise1`），挤得越紧抖得越厉害，就有"受力"的感觉。
- 墙每拍砸一次，间距用带过冲的 whip，字的变形跟着间距过冲，自然有回弹。
- 被挤出来的字按**阅读顺序排成一行**飞出（每个字错开 0.6 帧），而不是四散乱飞，否则读不出来。

## 5. 从句子里留下一个字当主角

- 句子里第一个字（「我」）位置可以精确算（左对齐时 = 左边界 + 半个字宽），其余字落下：重力（位移 ∝ g²）+ 随机旋转 + 淡出，按字序错开。
- 主角字单独渲染在同一位置，句子里那一格留空，切换时看不出接缝。

## 6. 像素字和"生成过程"

- 16×16 位图（`#` = 亮）画字，一个 `alpha(行, 列, 是否亮)` 函数控制每格透明度，同一个组件就能画：
  - 噪点：`alpha = 平滑噪声`（连续变化，别按帧跳）
  - 去噪：`lerp(噪点, 目标, 进度)`
  - 部分显示：只画排序在阈值以内的格子
- "部分的我"一开始用随机顺序点亮，结果像一地碎屑；改成**从上到下的光栅顺序** + 一条扫描线，一看就是"还在加载"。
- 每次补格子时让新格子闪一下，并让整个字"呼吸"一下，否则变化太小，在画面上几乎察觉不到。

## 7. 图层拆分（"拆解别人的作品"）

- 平铺图层的等距视角：`transform: scaleY(0.56) rotate(-36deg)`，纯 2D，比 CSS 3D 好预测，标签位置也好算。
- 原片在最下面，每拍从里面抽出一层往上抬（光线 → 运镜 → 提示词）。**没被抽出的层要透明**，否则一开始原片上就盖满了文字和线条。
- 标签放在 2D 空间、跟着图层高度走；注意窗口的 `overflow: hidden` 会把靠右的标签裁掉。

## 8. 其他小技巧

- 渐变字：`backgroundImage` + `backgroundClip: "text"` + `color: transparent`。
- 字宽估算（不读 DOM）：全角字正好 1em，拉丁字母按字母查表（I ≈ 0.32em，M ≈ 0.9em），等宽字体 0.6em。用于居中和摄像机跟随足够准；需要精确对齐的地方把元素放进同一个容器里相对定位。
- 不要在渲染时用 canvas 测量字体：第一次渲染时字体可能还没加载好，测出来的值会被缓存。
- 元素"出现"之前就渲染在场景里，会在不该出现的时候被镜头拍到（比如语言模型的方块在静音段就露了脸）；用一个"从某一拍开始存在"的开关。
- 背景文字墙：每行交替方向，每 8 分音符在前 2 帧内步进一格，其余时间静止，节奏感比匀速滚动强得多。

## 9. 扁平插画场景（北海片）

- 整个场景是 SVG，坐标 x 从 −400 到 2320、y 从 0 到 1080，比屏幕宽一圈，摄像机离开场景中心时也盖得住。
- 程序化的小部件在 `src/butterworth/draw.tsx`：
  - 椰树：二次曲线的树干，叶片长短用 `hash` 随机，整棵随 `noise1` 摆。
  - 山脊：沿 x 每 40 px 用 `noise1` 取一个高度，再用 Catmull-Rom 平滑成曲线（`smoothPath`）。
  - 上升的烟（蒸汽、香、烤肉烟）：几条曲线随时间上升、变细、淡出，循环错开。
  - 海鸥：一个会扇动的“V”。
  - 灯笼和灯串：挂点用 `sagPoint` 算，它和二次贝塞尔曲线的点对得上，灯笼正好挂在画出来的线上。
- 太阳倒影：太阳正下方画一列横短条，越往下越宽、越暗，每条用 `noise1` 左右抖。这一层 k = 0，太阳在屏幕上不动，倒影也跟着不动。
- 一天的天色：每个场景给头尾两组天空（顶、中、地平线三色，太阳位置、大小、颜色，星星、月亮的透明度），停留时从头渐到尾，甩镜时渐到下一场景。日落场景的太阳从山脊上方沉到山脊后面，靠的就是这个。
- 坑：
  - 远山半透明，太阳会从山“前面”透出来；远山要不透明，太阳才是从山后升起、落下。
  - 鸟正好飞过太阳，看起来像一张皱眉的脸；鸟的路线要避开太阳。
  - 灯泡只画一个半透明圆，看起来是灰色的；要用径向渐变，中心亮、往外淡出。
  - 庙顶的主脊画成一条横杠放在三角形屋面上，接不上，像悬空的金条；屋面要画成梯形，顶边就是主脊，两端再起翘。
  - 道具画进了标题区（左下）：见 README“文案”。

## 10. 地图（北海片）

- 海岸线来自 Natural Earth 1:10m 陆地数据（公有领域），用一次性脚本裁出要的经纬度范围（脚本没存进仓库）；槟城岛在数据里只有 41 个坐标，取 30 个再用 Catmull-Rom 平滑，就不像折线了。坐标存在 `src/butterworth/geo.ts`。
- 投影：等距圆柱乘纬度余弦，`x = (经度 − 经度0) × cos(纬度0) × K`、`y = −(纬度 − 纬度0) × K`，K = 3600 px/度。
- 地图整体缩放时，线宽和虚线长度都除以缩放倍数，屏幕上的线宽不变；路线“画出来”用 `strokeDasharray`，实线长度 = 路径长度 × 进度。
- 地名用 HTML 叠在 SVG 上面，位置由投影算，字号不跟着地图缩放。
- 等高线用岛的形状做 `clipPath` 裁掉，否则会溢出海岸。
- 坑：标签压在路线上（“Butterworth”压着铁路）、标签出了画面（“威省”）。标签摆好后渲一张静帧看。

## 11. 照片入片（槟城大桥片）

- 网上找的照片多半只有 460–720 px 宽，满屏放大 2.7 倍会很糊。做成“相片”：照片按接近原尺寸放在画面右侧，背后铺同一张图的模糊放大版（压暗、加饱和），相片和底图反向慢移，就有了视差。老照片再加白边、轻微旋转和做旧／黑白滤镜。
- 模糊底图很贵：先把它画成 480×270 的小元素、`blur(9px)`，再整体放大 4.5 倍，效果接近大半径模糊，计算量小得多。
- OSM 地图截图上叠动画：按颜色把桥（粉红）和渡轮航线（蓝色虚线）的像素描出来，坐标存成这张图的像素（`src/penang/overlays.tsx`）。图片和 SVG 用同一套铺满计算，放进同一个缩放容器，线就一直贴着地图。换一张地图截图就要重新描。
- OSM 的浅色底上，暖色光线看不清：地图整体正片叠底一层深蓝（不透明度 0.55），光线加粗、加外发光。
- 照片会压到左下的标题，和北海片的道具一样；相片的位置、大小写进 props（`print.x / y / height`），看静帧再挪。
- （槟城大桥片第二版）逐字打出：整行先按最终位置排好，没出现的字透明，第 i 个字落在离 `at + i × 拍数 ÷ 字数` 最近的八分音符上（`captions[i].typeBeats`）。
- （槟城大桥片第二版）几条字幕同时在画面上时，暗色衬底要统一先画、文字统一后画，否则后一条的衬底会提前盖住前一条的字。
